In internal.rs, Emit runs output and error constructors and Check
suppresses them when a combinator discards the result. Complete and
Streaming decide whether short data produces an error or a request for
more input. Branch and sequence combinators use these modes when
choosing alternatives, tracking permutation matches or discarding an
output. The wrappers in combinator/mod.rs pass caller-owned callbacks
and borrowed input through these modes. The byte and character parsers
consolidate their mode-specific implementations around Input, and the
bit and numeric parsers read supplied input using iterators and bounded
byte widths. The new string fast paths slice at offsets from str::find
or the string length. Range repetition checks progress before growing
a collection, and count-based combinators limit initial reservation
based on element size. These paths transform the caller's data and
do not add filesystem, process, network or credential access. The
remaining changes to the library exports, errors, docs and fixtures
adapt to the Parser and Input APIs and exercise range repetition,
arrays, error ownership, float parsing and precedence.

**Nonblocking observation.** EscapedTransform::process in
src/bytes/mod.rs compares the child remainder length with the original
input length. If the normal parser consumes a prefix and later
succeeds without advancing on a nonempty remainder, the index can
stop advancing and the loop can consume CPU or grow the output.
Both 7.1.3 escaped_transform implementations have the same comparison.
Infumap resolves Nom with std and alloc through av1-grain. Its film
grain table parser uses complete text primitives, repetition and
sequence combinators and does not use escaped_transform. The
observation does not establish a new safe-to-run violation in this
delta. LengthCount also sizes its initial reservation using the
count parser's output type rather than the element parser's output
type. The stated 64 KiB cap can therefore be exceeded with large
element types. Av1-grain does not call LengthCount.
