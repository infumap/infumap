# Using Infumap on macOS

## Trackpad settings

Right-click is a core part of Infumap navigation: it takes you back. On a Mac trackpad, a two-finger tap provides the same action.

Open **System Settings > Trackpad** (called **System Preferences > Trackpad** on older macOS versions):

- Under **Point & Click**, enable **Secondary click** and select the two-finger option.
- Under **Scroll & Zoom**, turn off **Smart zoom**. This gesture uses a two-finger double-tap; disabling it reduces the wait for a possible second tap, making Infumap's back navigation more responsive.
- Under **More Gestures**, consider turning off **Swipe between pages** to avoid accidentally navigating the browser's history while using Infumap.

See Apple's [trackpad settings guide](https://support.apple.com/guide/mac-help/mchlp1226/mac) for more about these controls.
